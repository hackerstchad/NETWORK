# 🌐 Network Protocol Trainer

Application éducative avancée en **Python + Tkinter** pour apprendre les acronymes et les protocoles réseau par catégorie (couche OSI/TCP-IP, routage, sécurité, IoT, industriel, etc.).

## ✨ Fonctionnalités

- **📚 Mode Apprentissage** : explore chaque protocole avec sa catégorie, sa définition, son port/identifiant et un moyen mémotechnique.
- **🎮 Mode Quiz** : répondez à des questions variées (acronyme ↔ nom, port, couche OSI, catégorie, QCM).
- **⚡ Mode Contre-la-montre** : 60 secondes pour répondre correctement le plus possible.
- **🏆 Classement** : scores sauvegardés localement avec date et mode.
- **🔎 Filtres & recherche** : trouvez rapidement un protocole.
- **🎨 Interface moderne** : thème clair/sombre, cartes, onglets, tooltips.
- **📝 Statistiques** : suivi des progrès et des catégories maîtrisées.

## 🚀 Lancement

```bash
pip install -r requirements.txt
python network_protocol_trainer.py
```

## 🛠️ Dépendances

- Python 3.8+
- tkinter (inclus avec Python sur la plupart des OS)

## 🧠 Conseils d'utilisation

1. Commencez par le **Mode Apprentissage** pour lire les définitions.
2. Passez au **Mode Quiz** pour tester vos connaissances.
3. Utilisez le **Mode Contre-la-montre** pour réviser sous pression.
4. Consultez les **Statistiques** pour identifier vos points faibles.
